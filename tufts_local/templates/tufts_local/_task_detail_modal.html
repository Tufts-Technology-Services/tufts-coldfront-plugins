{% comment %} One modal for the whole report, filled from whichever button opened it. Why a modal rather than the popovers this page used to use: coldfront 1.1.9 creates popovers once, on DOMContentLoaded (static/src/bs.ts initPopovers), and its htmx:afterSettle hook re-runs initDataTable alone -- so a popover in content swapped in later never gets an instance. The tables here re-poll themselves every few seconds and the Ack cells are replaced on click, which is exactly that case. A page script cannot make one either: the bundle exports nothing, sets no window.bootstrap, and never registers Bootstrap's jQuery plugins, because it exposes window.jQuery further down the same module than the point where Bootstrap looked for it. Bootstrap's modal click handler, by contrast, is delegated on document, so it picks up buttons that arrive long after load with no help from us. {% endcomment %}
